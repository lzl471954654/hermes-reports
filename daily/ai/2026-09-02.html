Claude Fable 5.1 把 agent token economics 又砍一刀：缓存命中价 -75%

9 月 1 日 Anthropic 同时发布 Claude Fable 5.1 与 Claude Mythos 5.1——同一个底层模型挂两套不同强度的安全挡板，Fable 走公开商用、Mythos 只给审核通过的高敏感客户。官方把它定位为"agentic coding、长时任务、知识工作"的旗舰，定价 $10 / $50 / $0.25（input / output / cache hit，每百万 token）。

最炸的不是 benchmark，而是这一行：cache hit 从 $1.00 直接砸到 $0.25——75% 相对降幅。在长 agent 任务里，cache hit 通常占总 token 的 60-80%（多轮 system prompt + 工具 schema 反复读），这意味着同一条 agent 流水线的成本能直接砍掉 40-50%。

为什么这是今天最重要的事？

  • 这是 Anthropic 对 DeepSeek V4-Pro 永久降价 75% 的正面回应。当开源把 input/output 砍到地板价，闭源只能从自己最擅长的"上下文重复读取"场景反向开刀——而这恰好是 agent 时代最值钱的成本项。
  • agent token economics 出现"双向收敛"：开源在砍基础 token、闭源在砍 cache token。结果是一样的——长上下文、长 session、多工具的 agent 终于在经济上跑得起了。
  • 对 agent 开发者的实际行动：今天就去重新算一遍你的 agent 流水线的 cache hit 占比——你大概率会发现 prompt caching 本来就能直接套上 Fable 5.1，零代码改动拿到 40% 成本下降。Cache write 价格 $12.5 仍偏高，但高频读场景稳赚。

MCP-Universe RL：第一个真正"按 MCP 训练 tool-use agent"的开源 RL 框架

arXiv 2608.22167（8 月 22 日提交）——MCP-U RL 把所有训练环境和工具都用 MCP 协议暴露，任何已有 MCP server 直接接入训练，零 RL 专用胶水代码。核心创新：把"tool waiting"移出 GPU 关键路径，让外部调用挂起时 GPU 能继续跑别的 trajectory。
