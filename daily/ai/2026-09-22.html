Grok 4.7 发布：「同价加量」的价格战，和被抢跑的 Opus 5.5

P0

模型发布

Coding Agent

xAI 于 9 月 21 日发布 Grok 4.7，定位「coding 与知识工作的最强模型」。核心卖点不是降价，而是同价加量：$2/M input、$6/M output，与 Grok 4.6 完全持平，但 HN 社区指出其 weights 比 4.6 多约 40%。官方说法是「在困难任务上工作更久、更仔细地自查」。

独立评测怎么说？Artificial Analysis 的实测（Benchmarking Grok 4.7）显示：Coding Agent Index 从 47 分升至 56 分，反超 GPT-5.6 Sol；三个分项全线上涨——DeepSWE v1.1 从 65%→73%，Terminal-Bench 4.0 从 18%→33%，SWE-Atlas-QnA 从 58%→63%。但 The Decoder 等媒体也直言：综合智能榜仍与 Claude / GPT-6 Astra 有明显差距。

为什么重要——三点：

① 前沿定价进入「电力市场」模式。对比 DataCamp 的数据：Grok 4.7 比 GPT-6 Astra 便宜约 5 倍（input）/ 8 倍（output）。但注意打法变化——2024-2025 年是「新模型更便宜」，2026 年下半年变成「价格锁死、暗中堆料」。单位智能的价格趋稳，厂商靠架构效率提升利润率。这意味着：别再等「明天会更便宜」，该比的是同价位下的 agentic 产出质量。

② Coding Agent Index 成为新发布会的核心 KPI。Grok 4.7 的宣传物料里没有 MMLU、没有 GPQA，全是 agent 指标。Benchmark 的话语权已经从学术榜转移到 agentic 实战榜——这是行业重心转移的最直接信号。

③ 时机耐人寻味。发布选在传闻中 Opus 5.5 上线的前一天（r/ClaudeCode 曝光代号 claude-wafer-eap，Polymarket 给出 92-95% 的本周发布概率）。Musk 同期放话 Grok 4.9 将达「Astra/Fable class」。对 agent 开发者的 action item：如果你的 agent 跑长任务、预算敏感，Grok 4.7（尤其 xhigh 档）值得进你的模型路由池做 A/B；但涉及高可靠性长程任务，第一梯队（Claude / GPT-6）仍是安全区。

💭 深度思考

洞察一：「同价加量」是效率革命的隐藏形态，小模型的机会窗口在 agent 长尾

把今天三条线放在一起看：Grok 4.7 同价堆 40% weights、GPT-6 Astra 维持 2 倍溢价、中电信用 4B 激活的 MoE 把 agent 推理成本打到地板价——前沿层的「单位智能价格」正在锁死，而不是继续下跌。厂商不再用降价抢市场，转而靠架构效率赚利润。

这反而定义了小模型的生存空间：agent 工作流里 80% 的中间调用（路由、抽取、格式化、校验）根本不需要 frontier 智能。当 frontier 价格不再跳水，「够用的小模型 + 贵的 frontier 兜底」的分层路由就从「省钱技巧」变成「架构标配」。今天中电信星辰和 ADK Android 端侧方案都在回答同一个问题。给 agent 开发者的具体建议：审计你的 token 账单，找出可以降级到 4B-30B 级别的调用类别，今年内把分层路由做进生产。

洞察二：Coding agent 已从「助手」变成「生产资料」，你的度量体系跟上了吗？

三件看似无关的事指向同一趋势：Anthropic 给「AI 承担 26% 研发」记账、Linear 敢于让 agent 重构 CI 并把测试规模×4、Grok 4.7 的发布会直接以 Coding Agent Index 为主 KPI。当三方（模型厂、应用方、评测方）都用生产指标而非学术 benchmark 说事，coding agent 的身份已经变了。

多数团队还在用「token 消耗」「任务完成率」这种粗粒度指标管理 agent。Linear 的案例给出了更进一步的信号：agent 化的真正红利不是省人力，而是解锁原本因成本被放弃的工程实践（比如 4 倍厚的测试）。主观判断：未来 12 个月，衡量 agent 落地成熟度的核心指标会是「agent 产出的评审通过率 / 回滚率」，而非「省了多少工时」。建议从本周开始，为你的 agent 建立这两条基线。
