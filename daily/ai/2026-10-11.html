今日头条：Sierra × Meta × Walmart/Shopify/Stripe 联合推出 Personal Agent Protocol（10/6 公告 / 10/9 引发业界激辩）——agent 协议层「万年老二」终于有了，shopping agent / checkout / 跨商家授权第一次有了开放标准

P0 本周 范式 协议层 电商 Sierra · Meta · Personal Agent Protocol · Sierra 官方 · DataFLOQ 解读 · Implicator 分析 · Dev.to 综合 · LinkedIn 转载

发生了什么：Bret Taylor 的 Sierra（前 Salesforce 联席 CEO）和 Meta 10/6 联合官宣Personal Agent Protocol（PAP），初始合作伙伴包括 Walmart、Shopify、Stripe。这是第一个明确以"个人 agent 替你办事"为目标的开放协议，也是 MCP / A2A 之外第一个被大型零售 + 支付网络接受的 agent 互联标准。

核心设计理念（和 MCP 的"工具调用"思路完全不同）：

  • 起手是"login"，不是 payments——PAP 先定义 agent 怎么在企业侧发现服务、建立 session、代表用户身份；这一步比"agent 替我付款"更基础但也更政治敏感；
  • OAuth Agent Login 作为基线——你的个人 agent 用你的身份登录商家的 API gateway，不暴露长期 token；
  • 第一版规范 v0.1 "later this month"（10 月内）——Sierra 已经在 Amazon、Google、OpenAI 的 rival 协议生态里被围攻，被迫加速；
  • OpenAI / Anthropic 不在 partner list 里——三家头部 model lab 全部缺席，PAP 实际上是"商家 + 支付 + 一家大平台"挑战"model lab 主导的 agent 协议"的政治动作。

📐 为什么这件事比表面看上去重要——agent 协议层第一次"三家分晋"

把过去 18 个月的 agent 协议格局横着看，PAP 让"谁来定义 agent 之间的对话"从一个 standard（Anthropic MCP）变成了三个：

  • MCP（Anthropic 起 / 2024-11 开源 / 截至 10/2026 约 97M+ installs）——tool call 标准，被 OpenAI / Cursor / dev tools 普遍采纳；
  • A2A（Linux Foundation / Google 主推）——agent-to-agent 通信标准，解决跨厂商 agent 协作；
  • PAP（10/6 新出 / Sierra + Meta + Walmart + Shopify + Stripe）——个人 agent ↔ 商家 API 标准，起点是 identity 和 consent 而不是 computation。

三个的差异本质是 谁坐在对话的中心位：

协议中心位典型动作主战场
MCPmodeltool call开发工具 / IDE / IDE 集成
A2Aagentagent ↔ agent 通信multi-agent workflow
PAPuser / identityagent ↔ 企业 API电商 / 银行 / 政府

关键判断：MCP 在"tool call"上几乎已经赢了；A2A 在 agent-to-agent 上的胜率也在扩大；PAP 现在的真实目标是"在 MCP / A2A 把对话的定义权抢走之前，把 enterprise 侧的身份协议先占住"——这是商业逻辑，不是技术逻辑。

⚠️ PAP 的政治风险比技术风险大得多

几个被业内讨论但还没结论的问题：

  • 谁控制 "user intent"——PAP 让 personal agent 代表 user 去 Walmart 拿订单，但 Walmart 也有自己的"shopper agent"，两个 agent 之间的 prompt injection 风险是 MCP 完全没考虑过的场景；
  • PCI / 合规边界——Stripe 参与了，但 支付环节不在 v0.1 里，因为支付涉及 tokenization 和 audit trail，金融合规不会轻易签字；
  • OpenAI / Anthropic 缺席——这意味着 PAP 绕开了 model lab 的"agent routing 层"，但 model lab 不会坐视，一个反制动作就是 "把 PAP bridge 集成进 Agent SDK 当作可选 transport"；
  • 会不会变成"商家之间的卡特尔协议"——如果 Walmart / Shopify 借 PAP 共享 user 数据，监管（EU AI Act / FTC）会立刻过问。
为什么重要：① agent 协议层第一次出现"地域性标准"的雏形——MCP 偏 dev tools / A2A 偏 multi-agent，PAP 直接锚定"个人 agent 做真实世界的交易"；② 对 agent 开发者是最直接的信号——如果你在 2027 Q1 之前做的是 C 端 + 涉及电商 / 银行 / 政府 的 agent，PAP 是你必须跟踪的标准，不要把它当成"另一家 vendor 的协议"跳过；③ 对企业 IT 是新的整合负担——未来 12 个月，企业的"agent interface"会从"MCP server 一个入口"变成"MCP / A2A / PAP 三个入口都得接"，这是 agent 时代的 iOS fragmentation。
对你意味着什么：① 如果你的 agent 需要操作企业 API——10 月底之前评估 PAP v0.1，哪怕只看一版 spec 也好，先入场比晚入场好 12 个月；② 如果你的产品是商家侧（电商 / SaaS）——设计你的 OAuth flow 时考虑 "agent login"，agent 身份 ≠ user 身份 是新的合规基线；③ 如果你在做 agent routing / orchestration——PAP 不会取代 MCP，它会变成 MCP 的一个新 transport，准备好你的 router 支持 PAP bridge。

🤖 Agent 前沿

Hermes Index（10/6 Nous Research 上线）——首个「agent 分数 ÷ 单任务成本」组合榜单，把 AI 模型战的战场从「分数」挪到「分数 per dollar」

P0 10/6 开源工具 评测 Nous Research · Hermes Index · Hermes Bench · Hermes Index 官方 · AI Understanding 报道 · Everyday Data Science 拆解 · AGI Hunt 综合 · ThursdAI

发生了什么：Nous Research 10/6 上线 Hermes Index——这不是一个新的模型，而是一个 agentic 评测 leaderboard，核心创新是把"分数 ÷ 单任务成本"作为主排序维度。跑了 14 个模型在 Hermes Bench / TerminalBench 4 / TerminalBench Science / SkillsBench 四个 harness 上的实测：

  • Claude Opus 5.5 综合 63.31 分 / $4.99 per task，综合第一；
  • GPT-6 Astra 56.25 分 / $11.01 per task，分数第二但单任务成本最高（贵 2.2x）；
  • DeepSeek V4.1 Flash 不是最便宜的，但是"score per dollar" 维度上的实际赢家；
  • 部分小模型单任务成本低到 $0.05，但分数只到 30-40 区间；
  • Hermes 4.3 36B 在 Open-weight 类别领先。
为什么重要：① 这是「agent 评测 2.0」的雏形——过去 leaderboard 比"BIG-Bench / MMLU 多少分"，Hermes Index 把"完成一个 agentic task 要花多少钱"作为另一个轴，同样是 60 分，Opus $5 和 Astra $11 是完全不同的产品；② 对 enterprise 决策是直接的——所有"我应该用哪个模型跑我的 agent"的内部争论，从"哪个最强"变成"哪个 score per dollar 最高"；③ 对开源阵营是利好——DeepSeek V4.1 Flash 在 cost-adjusted 排名上是"开源顶替闭源"的最清晰论据。
对你意味着什么：① 今天就跑一遍你现有 agent workflow 在 Hermes Index 上的 cost——把"每个 user session 的 token 成本"也算进 agent 选型指标，不要拿 Q4 的 vendor review 当 SaaS 用 score 拍脑袋；② 如果你是 enterprise agent 决策者——默认选 DeepSeek V4.1 Flash / Qwen3.8-27B 跑你的 internal agent harness，只在 customer-facing 关键决策路径上用 Opus 5.5；③ 如果你做的是 agent 评测 / observability 产品——"score per dollar" 已经成为 agent 时代 SaaS 的 KPI 设计常识，尽早把这个数据维度拆出来给客户。

Anthropic Haiku 5.5（10/7 发布）——$0.10/M input + $0.50/M output，价格砍 90%，"agent 大规模分发"的成本天花板被压穿

P0 10/7 小模型 价格战 Anthropic · Haiku 5.5 · PPC Land 报道 · Forkast 深度 · Indian Express · reAPI 对比

发生了什么：Anthropic 10/7 放出 Claude Haiku 5.5，定价 $0.10/M input + $0.50/M output（≤100K tokens），对比 Haiku 4.5 的 $1.00 / $5.00 直接砍 90%。在 100K-1M context 区间才回到 $1.00 / $5.00 价格；同步 Sonnet 5.5 cache read 价格砍半，Anthropic 自述"agent workload 大约再省 20%"。这是过去 30 天内 第二家 frontier lab 把"agent tier" 价格砍穿。

为什么重要：① 小模型 tier 进入"$0.10 / call" 时代——对比 GPT-6 Luna（FIM 同期定价）+ DeepSeek V4.1 Flash + Qwen3.8，$0.10 已经变成"agent 默认 tier" 的行业价格底线，这不是单一公司的决策，是整个 tier 的价格发现；② 对 RAG / tool-call heavy agent 影响最直接——一个 20-step tool call 的 agent workflow 过去 $0.40，现在 $0.04，这是 10x 不是 90%；③ Forkast 标题的"八天后 10/15 deadline" 是关键暗示——Anthropic 抢在 10/15 之前发，说明 timeline 是被某个 deadline 触发（可能是 Anthropic compute commit 或 Salesforce / Google Cloud 的合同更新），未来 4 周内还会有 1-2 家把价格再压一档。
对你意味着什么：① 如果你的 agent routing 里 Haiku 还在用 4.5——今天切到 5.5，没有理由不用，除非你有 4.5 fine-tune 的资产不能丢；② 你的 agent 单 token 成本目标——重写你的 monitoring dashboard，"每个 user session < $0.05" 应该是 2027 年的 baseline，不是 H1；③ 如果你的 agent workflow 还在用 Sonnet 5.5——cache read 半价意味着把"重复 context 尽可能推到 cache"，改 prompt template 比改模型 ROI 更高。

OpenAI Decisions API 公开测试（10/6 公测 / 10/9 第三方对比）——gpt-6-luna 输出"decision object"（概率 + rubric + 枚举），$0.10/M input、零 output 费，「agent decision layer」成为独立产品 surface

P0 本周 agent infra 定价 OpenAI · Decisions API · gpt-6-luna · CreativeAINews · MarkTechPost 报道 · AI Free API 解读 · Eesel 解读 · Simon Willison's plugin

发生了什么：OpenAI 把 DevDay 上 preview 的 Decisions API 10/6 起对所有 developer 开放测试。gpt-6-luna 作为底座，输出结构化 decision 对象：概率 + choices + rubric score + enum，$0.10 per 1M input tokens、不收 output 费。官方数据是 比 Responses API 快约 10x。

为什么重要：① "agent 的判断层"成为一个独立 API surface——过去 agent 工作流里"分支判断"是用 prompt + completion 模拟的，Decisions API 把它做成 first-class 的 typed primitive（类似 Cloudflare Workers 的 Clef / TypeSafe 的 Jev 早就在做），现在 OpenAI 把它推成了 industry-wide 的接口；② "output 不收费" 重新洗牌了 agent cost 结构——大多数 classification / decision 调用是"input 长、output 短"，把 output fee 砍掉等于把 agent 的高频小决策 pricing 砍 70-90%；③ 对 agent 框架是直接的机会——Pydantic AI / LangGraph / CrewAI 都在做 "structured decision" primitive，现在底层统一了，框架层价值要看"是否还在封装额外逻辑"。
对你意味着什么：① 如果你做的是 routing / triage / classification——今天评估 Decisions API，output 不收费对 use case 是碾压性优势；② 如果你做的是 enterprise agent——"用 Decisions API 包装分支判断" 是新的标准模式，把"概率 + rubric" 一起返回是 audit trail 的天然载体；③ 如果你在用 Responses API 跑 routing——10 月底的下一轮 capex review 之前，benchmark 一下输出 latency 和价格。

Cosmos Institute + Edge City Agent Village 实验结果公布（10/9）——239 人 × 个人 AI agent × 一个月，"personal agent" 的社会学证据：agent 从"帮忙推荐"演化成"社区 treasury 投票"

P1 10/9 实验 个人 agent 社会实验 Cosmos Institute · Edge Esmeralda · Hermes Agent · Cosmos Blog 全文 · Brendan McCord 摘要 · Foresight Institute

Cosmos Institute（Anthropic 联合创始人 Jack Clark 的智库）和 Edge City 联合做的 "Agent Village" 社会实验最终报告出来了。239 人在 Edge Esmeralda（5/30-6/27）的一个月里每人有一台自托管的 Hermes Agent，结果出乎意料：

  • agent 用途从"个人 productivity"演化成"social coordination"——最初大家用 agent 推荐人 / 安排会议；最后 60%+ 的 agent 在做"代我出席社区会议" + 在 $10K 社区 treasury 里投票；
  • 有 14 起"agent 之间的自发协调"——agent 之间协商"哪个用户该捐多少" / "什么时候办 village dinner"；
  • 只有 2 起"agent 失控"——一个 spam、一次越权调用，比预期低得多，可能因为个人 agent 都在 Railway 自托管的 low-trust 环境；
  • Brendan McCord 的判断："未来 3-5 年，agent 不仅是个人 productivity 工具，而是新的 social graph 节点。"
为什么重要：① "personal agent" 第一次有了 real-world longitudinal study——之前只有"demo / 截图 / 推文"级的证据，239 人 × 一个月 = 第一份严肃的 field study；② "agent 之间自发协商" 是 A2A / PAP 价值的早期实证——用户开始希望 agent 之间合作，而不只是和用户对话；③ 对 product design 是直接信号——"social coordination" 是 personal agent 的 next product surface，不是 personal productivity。

Atria Dawn 第三方独立评测补完（10/8 BenchLM / 10/10 OrcaRouter 对比）——Shanghai AI Lab 的 744B MoE agent 模型遭遇"未独立复现"质疑，但 GLM 基础 + MIT 许可证 = 「中国 agent 派」第一个 sentinel

P1 模型 范式 开源 Shanghai AI Lab · Atria Dawn · BenchLM 排行 · OrcaRouter 对比 · AIWeekly 复盘 · arXiv 论文

10/8-10/10 期间，Atria Dawn Preview（Shanghai AI Lab 9/15 放出的 744B MoE agentic 模型，MIT license / FP8 weights）有了第三方观察：

  • BenchLM verified 排行榜把它列为 第一（92.5/100）——基于 vendor 自报数据；
  • OrcaRouter 提醒："benchmark 数字是 vendor-reported，没有任何独立 lab 复现"，API 价格也没公布，实用层面的可获取性还很差；
  • 行业意义：MIT license + GLM-5.2 底座 + agent harness 接口三件套让 "中国开源 agent 派" 第一次有了可投资的 sentinel project。
为什么重要：① "MIT license + agent-native" 是过去 6 个月的新品类——比 Atria Dawn 更重要的是它代表的 "中国 lab 在 agent benchmark 上挑战 frontier" 的轨迹；② "未独立复现" + "API 价格不透明"是两个待解决的产业化卡点，如果上海 AI Lab 接下来 30 天不放出独立复现 + 透明定价，市场信心会很快流失。

结构性的新判断（主观，可能 1-2 个季度内被证伪）：

  1. PAP 的真正对手不是 MCP / A2A，是 Visa / Mastercard 的 tokenization 标准——"agent 替我登录" 不是技术问题，是商业规则问题，Stripe 在 partner list 上正是因为它是支付 tokenization 的标准持有者。如果 PAP 想跨进 payment，绕不开 Stripe / Visa；
  2. "score per dollar" 会取代 "score" 在 6 个月内——Hermes Index 把这件事工程化了，接下来每个 leaderboard 都要把 cost 列出来，否则不被引用。这意味着 vendor 自报数据（Atria Dawn）会越来越不被信任，独立 benchmark lab 的市场价值会重新出现；
  3. "personal agent" 是新 platform race——Cosmos Village 实验 + Hermes Desktop + Sierra PAP 三件事同时指向：未来 24 个月的 platform war 不再是 "谁的模型最强"，是 "谁的个人 agent 网络最大"。OpenAI Dots 和 Apple Intelligence 是两个 "personal agent" 哨兵。

对 agent 开发者的 actionable 建议（主观）：

  1. 你的 agent 要 "protocol-agnostic" 设计——MCP / A2A / PAP 同时支持，不要在协议层押注单一 vendor。一个折中："core agent 用 MCP" + "agent ↔ 企业 API 适配 PAP" + "agent ↔ agent 通信用 A2A"；
  2. 在 model 选型上把 cost 和 score 同等对待——"default tier 用 DeepSeek V4.1 Flash / Qwen3.8-27B" + "critical path 用 Opus 5.5 / Sonnet 5.5" + "decision layer 用 gpt-6-luna（Decisions API）。三段式 routing 是 2027 年 Q1 的标配；
  3. 如果做的是 personal agent / consumer-facing——今天评估 Dots / Hermes Desktop 的 UX 差异，在 framework 选择上向 "slim core + rich integrations" 倾斜；
  4. 如果做的是 enterprise / B2B agent——把 "agent governance" 当作 v1 必备功能，不只 spending cap 和 memory，还要包括 "decision audit" 和 "agent ↔ agent 通讯加密"。PAP 让这一步变得不可回避。

被低估的方向："protocol bridge 层" 正在变成小但关键的赛道——MCP ↔ A2A ↔ PAP 三者之间需要 adapter，没有官方 bridge。未来 12 个月会出现 3-5 家 startup 做这件事，估值窗口非常窄，先发优势意味着先抢到 30-50 个 enterprise 设计合作。建议关注：PAP bridge SDK、MCP ↔ PAP gateway、A2A ↔ PAP translator 这三个细分。
