  1. 竞争轴心变了。官方通稿通篇讲「long-running agents」「多步任务中不掉链子」「长轨迹上开始出现自我测试和自我验证」。这说明 frontier 厂商已经意识到：单发 benchmark 分数已经卷到头，真正的差异在长程可靠性——一个 Agent 跑 100 步后还知不知道自己在干嘛。

Ouroboros：能「改写自己核心代码」的 coding agent，三项 benchmark 刷新 SOTA

P0 · Agent 架构 arXiv:2608.08311 · 8月11日 v2

这篇论文是今天 Agent 板块真正的硬货。Ouroboros 是一个自进化（self-developing）的 agent harness——它的工具、prompt、上下文组装方式、甚至核心实现，都会通过「经过 review 的 commit」持续改进，而这些改进会成为后续工作的 runtime。

两种进化模式：

  • 递归自由进化：把「改进自己」本身当成一个任务，完成一轮进化就能调度下一轮；
  • 经验驱动进化：日常工作和社交交互暴露出的 bug、粗糙边角、低效的上下文构造，触发结构性的代码改动。

成绩很硬：Terminal-Bench 2.1 达 86.74%（Opus 5 驱动，benchmark 上目前最好成绩）、OSWorld-Verified 90.69%（超过此前最好）、CL-Bench 五轮 rollout 归一化 reward 0.2301（新 SOTA）。更特别的是「Hope」——一个已运行 161 天的公开「活体」agent 实验，在受治理的人类沟通下持续自由进化。

这意味着什么：昨天日报讲了 Prime Agent 的「prompt-as-a-variable」，今天 Ouroboros 把这一哲学推到底——连 harness 本身都是可编程、可进化的对象，而不再是一个固定设计。作者阵容里有 Roman Yampolskiy（AI 安全领域知名学者），所以论文也把「操作安全」摆到核心：一个能改自己代码、换自己模型 API 的 agent，它的 guardrail 必须在进化和公开社交压力下依然保持权威。

给 Agent 开发者的启示：你现在写的每一个 agent，代码里都可能已经潜藏着「让它自我改进」的种子。至少值得做两件事：一是给你的 agent 一个可审计的「自我修改」通道（带 review 的 commit，而不是直接改内存）；二是认真对待运行期权限——Ouroboros 的核心教训是，进化能力越强，越需要「权威性不受进化影响」的安全边界。

P1 · MCP 生态 8月5日 · Google Developers Blog

💭 深度思考

📌 观点一：竞争轴心正式从「单点 benchmark」转向「长程可靠性」

把今天的三件事摆在一起看，指向是同一个：

  • Grok 4.6 通稿第一句就是「long-running agents」；
  • Ouroboros 的核心卖点是「161 天活体进化」和「经验驱动的自我修正」；
  • 「Transformers 用不好世界模型」的论文，正好从机制层解释了为什么长程任务这么难。

这不是巧合。单发 benchmark 已经卷到边际递减，下一个战场是「一个 agent 连续跑几十上百步之后，能不能不掉链子」。而长程可靠性恰恰是当前所有模型最弱的环节——Grok 4.6 的 Terminal-Bench 只有 26%（远低于 Sol 的 34.6%），就是最好的证据。

Actionable 建议：别再用单一的 SWE-bench 分数选模型。给候选模型跑一条你自己的「长程任务」——比如「从空仓库开始，独立完成一个 feature 并自己测试修复」——看它第 30 步、第 80 步的表现。你真正需要的评测，是在你的工作流长度上测出来的。

📌 观点二：模型正在「零件化」，harness 和编排层才是新的护城河

今天的 WorldClaw（跑在 Claude Opus 4.8 上）、Ouroboros（自进化 harness）、以及昨天 Prime Agent、Google Tunix，都在说同一件事：模型本身越来越像可替换的零件，价值正在上移到 harness、编排和评测层。

证据很硬：腾讯做「3D 开放世界」这样的 headline 产品，用的不是自研模型而是 Claude Opus 4.8 当大脑；Ouroboros 的三个 SOTA 成绩，全部是「Opus 5 + harness」打出来的，而非一个新模型。

对 agent 开发者的意义：如果你的竞争力建立在「用某个特定模型」上，那这个竞争力是脆弱的——模型换代速度以月计。值得长期投入的是模型无关的编排层：context 工程、工具协议（MCP）、评测、自我改进通道。这些不随模型换代而贬值，反而会随模型变强而增值。
